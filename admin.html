Supabase Setup Guide

Step 1 — Run the full schema SQL

Open Supabase → SQL Editor → New Query, paste the contents of schema.sql (in your project root), and click Run. This creates all tables, RLS policies, and seed data.

  1. Open your Supabase project at supabase.com/dashboard
  2. Go to SQL Editor → New Query
  3. Paste the full schema.sql file contents and click Run
  4. Refresh this admin panel — all sections will be live

Step 2 — Create the Media Storage bucket (required for image uploads)

  1. In Supabase, go to Storage → New Bucket
  2. Name it exactly: sandou-media
  3. Set Public to ON
  4. Click Save
  5. Then go to Storage → Policies and add a policy on sandou-media: allow INSERT for authenticated users
-- Run in SQL Editor to enable authenticated image uploads INSERT INTO storage.buckets (id, name, public) VALUES ('sandou-media', 'sandou-media', true) ON CONFLICT (id) DO NOTHING; CREATE POLICY "auth_upload" ON storage.objects FOR INSERT TO authenticated WITH CHECK (bucket_id = 'sandou-media'); CREATE POLICY "public_read" ON storage.objects FOR SELECT TO public USING (bucket_id = 'sandou-media');

No Storage bucket? You can still add images by pasting direct URLs — use the "Add by URL" buttons in the Media Library, Gallery Manager, and Page Editor image fields.

Quick admin policies (if you only need the fix now)

-- Run this in Supabase SQL Editor if tables already exist -- Admin access to orders/inquiries/subscribers DO $$ BEGIN DROP POLICY IF EXISTS "admin_select_orders" ON public.orders; DROP POLICY IF EXISTS "admin_update_orders" ON public.orders; DROP POLICY IF EXISTS "admin_select_inquiries" ON public.inquiries; DROP POLICY IF EXISTS "admin_select_subscribers" ON public.subscribers; EXCEPTION WHEN OTHERS THEN NULL; END $$; CREATE POLICY "admin_select_orders" ON public.orders FOR SELECT TO authenticated USING (auth.email() = 'teamloxen@gmail.com'); CREATE POLICY "admin_update_orders" ON public.orders FOR UPDATE TO authenticated USING (auth.email() = 'teamloxen@gmail.com') WITH CHECK (auth.email() = 'teamloxen@gmail.com'); CREATE POLICY "admin_select_inquiries" ON public.inquiries FOR SELECT TO authenticated USING (auth.email() = 'teamloxen@gmail.com'); CREATE POLICY "admin_select_subscribers" ON public.subscribers FOR SELECT TO authenticated USING (auth.email() = 'teamloxen@gmail.com');

Duplicate policy errors are safe to ignore. After running, refresh the dashboard to see your data.
